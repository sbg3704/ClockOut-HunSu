# hunsu-pencilflow (색연필 수식 흐름)

`hunsu-flow`(목록)·`hunsu-marks`(형광펜)의 수식 흐름을 **엑셀 칸 위에 손으로 그린 색연필 그림**으로 보여 준다. 선언만 있는 모듈(코드 없음)이고, 그리는 일은 앱의 표시층(`marks[]`의 `style: "pencil"`)이 한다(문법은 docs/12).

- 고른 칸은 주황으로 빙 두르고, 쓰는 칸(파랑)에서 고른 칸으로, 고른 칸에서 쓰이는 칸(초록)으로 휘어진 화살표를 긋는다. 이웃 칸은 색연필로 칠하고 둘러싼다. 손글씨 이름표(`A1 (쓰는 칸)` 등).
- 칸을 옮길 때만 처음에서 끝으로 "휙휙휙" 그려진다(약 1초 안). 스크롤로 자리만 바뀌면 움직임 없이 따라온다. 윈도우의 "애니메이션 효과"가 꺼져 있으면 움직임 없이 바로 그린다.
- 같은 칸이면 늘 같은 떨림이다(칸 주소가 씨앗). 한 묶음에 가까운 10칸까지 그린다.
- 데이터는 조회 `mark`(다리 0.0.014): 같은 시트의 보이는 칸만. 시트를 넘는 흐름은 목록 모듈 `hunsu-flowgraph`.
- `hunsu-marks`(단색 형광펜)와 같이 켜면 겹쳐 보인다. 하나만 쓰는 편이 깔끔하다.
- 이름표 글꼴은 Nanum Pen Script(OFL 1.1, 번들), 없으면 맑은 고딕.

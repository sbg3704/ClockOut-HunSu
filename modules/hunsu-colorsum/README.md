# hunsu-colorsum (색깔별 합계)

칼퇴 추가기능 `range-tools`의 "색깔별 합계"(RangeColor_Sum)를 패널로 옮긴 모듈(2026-11-16). 선언만 있다.

- 다리 조회 `color.sum`(다리 0.0.015, `CoHunsuQ_ColorSum.bas`): 선택 ∩ 사용 범위를 칸마다 읽어 채우기 색·글자 색별로 묶는다. 칸마다 `Interior.Color`를 읽어야 해서 2만 칸까지만 본다(넘으면 `truncated`).
- 추가기능과 달리 새 시트를 만들지 않고 패널에 바로 보여 준다. 칸을 눌러 같은 색 칸을 고르는 기능은 "선택 바꾸기" 명령이 필요해 보류(4-1 결정 후).
- 색 이름은 `#RRGGBB`로만 보인다(색 견본 부품은 아직 없음).

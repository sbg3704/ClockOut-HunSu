# hunsu-coldiff (두 열 비교)

칼퇴 추가기능 `value-tools`의 "두 열 다른 칸 선택"(ValueCompare_SelectDiff)을 선택을 바꾸지 않는 목록 + `goto`로 옮긴 모듈(2026-11-16). 선언만 있다.

- 다리 조회 `coldiff`(다리 0.0.015, `CoHunsuQ_ColDiff.bas`): 선택이 한 영역의 두 열일 때만 계산한다. 아니면 `ready:false`와 안내 문구.
- 비교 규칙: 글자는 대소문자·공백까지 같아야 같고, 숫자는 값이 같아야 같고, 빈 칸과 길이 0인 글자는 같다. 추가기능의 규칙과 같은지는 칼퇴 쪽 확인이 필요하다(README 미확인).
- 돌려주는 줄은 30개까지, 한 번에 5만 줄까지만 견준다.

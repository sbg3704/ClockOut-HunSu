# 선택 요약 (hunsu-selection)

훈수꾼 예제 모듈. 새 모듈은 이 폴더를 복사해 내용만 바꾼다(docs/01 3.4장 10번).

- `hunsu-selection.hunsu.json`: 모듈 선언(docs/01 4장). 자리 `edge-right`, 순서 100(늘 봐야 하는 상태).
- `view.json`: 화면 선언(docs/01 4.1장). 쓸 수 있는 것은 데이터 연결 `{주제.경로:형식}`과 조건 한 줄(`hideWhen`, `showWhen`)뿐이다.
  - 형식: 없음(그대로), `n`(천 단위, 소수 둘째까지), `n0`(천 단위 정수), `p`(백분율).
  - 조건: `경로 == 값`, `!=`, `>`, `>=`, `<`, `<=`, 또는 경로만(값이 있으면 참).
- 1단계에서 그리는 부품: `stat`, `text`, `badge`, `divider`. 나머지 부품 이름은 받아 두고 "준비 중"으로 그린다.

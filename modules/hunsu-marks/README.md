# hunsu-marks (칸 위 형광펜)

셀 위 표시층(`mark`)을 쓰는 첫 모듈. 선언만 있다(코드 없음). `view.json`의 `marks[]`가 어떤 자리 배열을 어떤 색·모양으로 칸 위에 그릴지 정한다(문법은 docs/08). 다리 조회 `mark`(다리 0.0.014, `CoHunsuQ_Mark.bas`)는 지금 보이는 칸의 자리만 화면 픽셀로 준다.

- 그리는 것: 오류 칸(빨간 테두리), 활성 셀이 쓰는 칸(파란 칠), 활성 셀을 쓰는 칸(초록 밑줄). 같은 시트만.
- 스크롤은 엑셀 이벤트가 없어 엑셀이 앞에 있을 때 `settings.json`의 `markPollMs`(기본 400ms) 간격으로 다시 묻는다. 0이면 선택·값 변경 때만.
- 표시층 창은 늘 클릭이 지나간다. 확대·모니터 배율에서 칸과 맞는지는 PC에서 눈으로 확인해야 한다.

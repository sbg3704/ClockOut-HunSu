# hunsu-folder (폴더 파일 목록)

칼퇴 추가기능 `sheet-tools`의 "폴더 파일 목록"(FolderList_Make)을 새 시트 없이 패널로 옮긴 모듈(2026-11-16). 선언만 있다.

- 다리 조회 `folder.files`(다리 0.0.015, `CoHunsuQ_Folder.bas`): 지금 책이 든 폴더의 파일(최대 200)을 이름순으로. 폴더 경로는 돌려주지 않고 폴더 이름만 준다. 책을 열거나 바꿀 때(`book` 신호)만 다시 읽는다. 폴더가 바뀌어도 책이 같으면 새로 고쳐지지 않는다(앱의 새로 고침 단추가 생기면 쓴다).
- 명령 `book.open`: 같은 폴더의 엑셀 파일(xls, xlsx, xlsm, xlsb, xlam, csv)만 연다. **셀 값을 바꾸지 않는 열기·이동**으로 보고 읽기 규칙의 범위로 판단했지만(docs/01 9장 8번), 사용자가 4-1 결정에서 "읽기와 이동만"을 더 좁게 보면 선언의 `commands`를 비우면 목록만 남는다.
- 새 시트로 내보내기(추가기능의 결과물)는 쓰기라서 4-1 결정 뒤로 미뤘다.

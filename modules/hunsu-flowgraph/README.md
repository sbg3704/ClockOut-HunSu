# hunsu-flowgraph (수식 흐름)

선언만 있는 모듈(코드 없음). 다리 조회 `flow.graph`(다리 0.0.014, `CoHunsuQ_FlowGraph.bas`)로 활성 셀의 앞쪽(쓰는 칸)·뒤쪽(쓰이는 칸)을 시트를 넘어 2단계까지 보여 준다. 다른 시트 칸은 굵게(활성 줄) 보인다. 줄을 누르면 `goto`.

- 같은 시트는 엑셀의 DirectPrecedents/DirectDependents, 다른 시트는 수식 글의 `시트!주소`를 읽어 찾는다.
- 뒤쪽 찾기는 책 전체의 수식(최대 2만 칸)을 한 번 훑어 캐시하고, 값이 바뀌거나 30초가 지나면 다시 훑는다. 그래서 무게는 heavy.
- 못 따라가는 것: 다른 통합 문서, 3D 참조(시트1:시트3!A1), 정의된 이름 안의 참조, INDIRECT·OFFSET.
- 2026-11-17: 예전 `hunsu-flow`(같은 시트 한 단계 목록)를 이 모듈에 합쳤다(사용자: 같은 정보가 두 패널에 중복). 맨 위 값·수식 줄과 파랑/초록 개수는 `flow.neighbors`, 나무는 `flow.graph`. 예전 id는 배치 파일에 남아도 무시된다.

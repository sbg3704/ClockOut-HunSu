# 시트 이동 (hunsu-sheets)

보이는 시트를 목록으로 보여 주고 누르면 이동한다(명령 `sheet.activate`). 지금 시트 줄은 밝게 칠한다(`activeWhen`).

- 데이터: 조회 `sheets`(다리 `CoHunsuQ_Sheets.bas`). 시트 바뀜·책 바뀜 신호에서 다시 조회한다(가벼움).
- 기본 자리는 왼쪽 도크(`place`). 오른쪽으로 옮기려면 모듈 관리자의 [오른쪽]을 누르거나 선언의 `place`를 `edge-right`로 바꾼다.
- 시트 이름을 바꾸면 신호가 없어 다음 시트 이동 때 갱신된다(엑셀에 이름 바꿈 이벤트가 없음).

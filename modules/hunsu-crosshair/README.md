# hunsu-crosshair (십자 음영)

칼퇴 추가기능 `cross-hair`(십자 음영)를 훈수꾼 표시층으로 옮긴 모듈(2026-11-16). 선언만 있다(코드 없음).

- 다리 조회 `mark`(다리 0.0.015)의 `rowband`, `colband`가 고른 칸의 행·열 띠 자리를 격자(pane)마다 한 장씩 준다. 영역을 여럿 골랐으면 활성 칸 기준이다.
- 추가기능은 조건부 서식을 걸어 실행 취소 기록이 지워지고 보호된 시트에 못 걸었다. 이 모듈은 엑셀 위 투명 창에 그려서 그 넷(실행 취소, 보호 시트, 칸 색 덮기, 재계산)이 없다.
- **PC에서 눈으로 확인할 것**: 스크롤하며 띠가 따라오는 지연(`markPollMs` 400ms), 확대·모니터 배율에서 칸과 맞는지, 틀 고정 시트. 확인되기 전에 추가기능을 카탈로그에서 내리지 않는다.
- 추가기능의 설정(표시 방식 선/음영, 색, 행·열 켜기, 시작 때 자동 켜기)은 아직 이어받지 못한다: 앱이 모듈 `params`를 읽는 코드가 없다(docs/11 3장). 지금은 파란 음영 하나다.

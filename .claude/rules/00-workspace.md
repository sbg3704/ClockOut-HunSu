# 전역 작업 규칙 (claude-workspace에서 배포됨 — 여기서 직접 고치지 말 것)

이 사용자는 계정 2개 × PC 2대(사무실/집, 각각 호스트+VM) = 4개 환경에서 같은 저장소를 번갈아 작업한다.
대화 내역과 자동 메모리는 다른 환경으로 넘어가지 않는다. **저장소에 적힌 것만 다른 쪽에서 안다.**

## 규칙 우선순위 (옛 방식 따라가기 방지, 2026-11-22)
- 이 문서는 저장소마다 `.claude/rules/00-workspace.md`로 **자동 복사**되어 Claude가 세션 시작 때 저절로 읽는다(별도 "읽어라" 불필요). 복사본 맨 위 `규칙 판` 날짜가 최신인지 본다.
- 충돌 시 **최신 규칙이 이긴다**: 사용자의 이번 대화 지시 > 이 공통 규칙·저장소 `CLAUDE.md`(날짜 최신 쪽) > `docs/` > `HANDOFF.md`·자동 메모리.
- `HANDOFF.md`·메모리는 **지나간 시점의 기록**이다. 거기 적힌 작업 방식·절차가 위 규칙과 다르면 따르지 말고, 어긋남을 사용자에게 알린 뒤 HANDOFF를 고친다.
- 새 규칙을 정하면 대화·메모리가 아니라 이 파일(공통) 또는 저장소 `CLAUDE.md`(그 프로젝트만)에 날짜와 함께 적는다.

## 세션 시작 시
1. 작업할 저장소에서 `git pull` 후 `git status -sb`를 확인한다. 미커밋 변경이 있으면 먼저 사용자에게 알린다.
2. 저장소 루트의 `CLAUDE.md`와 `HANDOFF.md`를 읽고, 그 내용에서 이어서 진행한다.
3. HANDOFF.md의 "주의점/하지 말 것"을 어기는 작업은 사용자 확인 없이 하지 않는다.

## 세션 종료(또는 "넘길게", "정리해줘") 시
1. `HANDOFF.md`를 갱신한다: 날짜·환경·브랜치 / 완료 / 진행 중 / 다음 할 일 / 결정사항과 이유 / 주의점.
2. 변경을 커밋하고 push한다. push가 안 되면 그 사실을 분명히 알린다.

## 금지
- 다른 계정·세션을 자동으로 호출하거나 트리거하는 구조(구독, 댓글 봇, 웹훅 연쇄) 만들기.
- 중요한 결정·지식을 자동 메모리에만 남기기 → 저장소 `CLAUDE.md`/`HANDOFF.md`/`docs/`에 적는다.
- VMware 공유 폴더 안에 저장소를 만들거나 그 안에서 git 작업하기.
- 비밀값(토큰, 키, 비밀번호)을 저장소에 커밋하기.

## 참고자료 (여러 프로젝트 공용)
- UI 배치·설정 등 참고할 외부 자료의 요약은 이 저장소 `references/INDEX.md`에 있다. 쓰기 전 `docs/참고자료_가이드.md`를 읽는다(방식만 참고, 원본·코드는 저장소에 넣지 않음).

## 패치노트 게시판 글 (모든 프로젝트)
- 패치 관련 글(설계로 "패치노트" 게시판에 올릴 글)은 이 저장소 `docs/패치노트_게시판_글_규칙.md`대로 만든다: 제목 한 줄(코드 블록, `프로그램 판번호 · 핵심 변화 3~4개`) + 에디터 [소스]에 붙일 HTML 조각(`templates/patchnote_board.html` 양식).

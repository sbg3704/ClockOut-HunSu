# 훈수꾼 (ClockOut-HunSu)

엑셀 창 위에 정보를 겹쳐 보여 주는 칼퇴(ClockOut)의 하위 프로그램입니다. 오류 난 셀, 수식 순서도, 시트 이동처럼 엑셀 안의 VBA만으로는 만들기 어려운 보조 화면을 오버레이로 띄웁니다.

- 상태: **기획 단계.** 구현은 구조와 규칙이 확정된 뒤에 시작합니다.
- 구조와 규칙 초안: [docs/01_구조와_규칙_초안.md](docs/01_구조와_규칙_초안.md)
- 이어받는 사람은 [HANDOFF.md](HANDOFF.md)를 먼저 읽으세요.

## 한눈에
- **다리**: 엑셀 안의 VBA 라이브러리(`clockout-hunsu`). 변화를 알리고, 물어보면 모아서 답하고, 이동 명령을 실행합니다. 읽기와 이동만 합니다.
- **틀**: 칼퇴 쪽에서 도는 WPF 프로그램. 오버레이 창, 자리, 패널 틀, 엑셀 연결을 맡습니다.
- **모듈**: 틀에 꽂아 내용을 채우는 단위(`hunsu-<이름>`). 화면 코드 없이 JSON으로 선언합니다.
- 배포는 칼퇴의 좌측 레일에서 받아 설치하는 방식입니다. 공개 ClockOut-Catalog의 Release를 씁니다.

## 이 저장소와 다른 저장소
| 저장소 | 역할 |
|---|---|
| `ClockOut` (비공개) | 칼퇴 매니저. 레일, 설정, 동기화, `ClockOut.Core` |
| `ClockOut-Catalog` (공개) | 추가기능과 하위 프로그램의 목록, Release |
| `ClockOut-HunSu` (이 저장소) | 훈수꾼의 틀, 다리, 모듈, 문서 |

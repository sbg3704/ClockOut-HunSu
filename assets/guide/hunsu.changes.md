# 훈수꾼 패치노트

## v0.0.191 (2026-11-17)
- 창 밖 사이드바를 넣고 기본으로 켰어요(오른쪽). 엑셀이 최대화면 엑셀을 남은 영역으로 줄이고, 아니면 엑셀 높이에 맞춰 옆에 붙어 따라가요. 안쪽 가장자리를 끌어 폭을 바꾸고 기억해요.
- 사이드바 아이콘은 묶음(상태, 점검, 이동, 수식...)마다 하나예요. 누르면 그 묶음의 모듈이 위아래로 함께 보이고, 쌓아 보기로 바꿀 수도 있어요.
- 묶음 아이콘은 그냥 끌어 순서를 바꿔요. Shift를 누른 채 끌면 묶음 합치기, 모듈을 다른 묶음으로 옮기기, ＋ 칸에 놓아 새 묶음 만들기가 돼요. 모두 기억해요.
- 모듈 아래 가는 손잡이로 높이를 바꿔요(두 번 누르면 자동).
- 아이콘 막대 맨 아래 단추: 설정 창, 모듈 관리, 모양, 작업 프로필, 보기 바꾸기, 남은 엑셀 정리, 사이드바 접기·펴기(» «). 접으면 아이콘 막대만 남아요. 사이드바 끄기는 설정 창과 훈 원 우클릭 메뉴에서.
- 패널 룩 3종(색연필 노트, 펜과 형광펜 기본, 먹빛 유리와 분필)을 넣고 껐다 켜지 않고 바로 바꿔요. 훈 원과 아이콘이 흰 시트에서도 잘 보이게 다듬었어요.
- 패널: 투명도 ◐ 막대로 부드럽게 조절, 제목줄 ▾로 본문 접기, 켜고 끄기 단추, 작게(아이콘으로), 본문 스크롤 막대.
- 떼어 낸 패널: 자석으로 붙은 것끼리 같이 움직이고, 여러 패널을 한 틀(엄마 패널)로 묶어요.
- 도크는 왼쪽에 반쯤 숨고 패널은 오른쪽에 쌓여요. 패널을 한 창처럼 합쳐 보는 설정도 있어요.
- 우클릭 빠른 설정과 설정 창 [옵션], 모듈 선언 단축키(수식 흐름 그리기 Ctrl+Alt+D)를 넣었어요. 수식 흐름 모듈은 하나로 합쳤어요.
- 닫힌 엑셀의 남은 EXCEL.EXE를 자동으로 정리하고, 「남은 엑셀 정리…」 창을 넣었어요.
- 고친 것: 훈수꾼을 켜 두면 엑셀 마우스 커서가 1초마다 '계산 중'으로 깜빡이던 문제(셀 위 표시가 화면이 그대로여도 계속 다시 묻던 것). 이제 스크롤·확대가 바뀔 때만 물어요.
- 고친 것: 패널을 줄이면 꺼지던 문제, 켜졌는데 아무것도 안 보이던 문제, 설정 창 글씨 잘림과 밝은 바탕에 밝은 글씨. 처리되지 않은 오류는 logs 폴더에 남겨요.
- 칼퇴 소개 화면에 판 번호, 사용법, 패치노트가 보여요.

## v0.0.073 (2026-11-16)
- 색연필 수식 흐름: 칸 위에 손글씨 색연필로 그리는 표시층. 칸 모양(네모, 대괄호, 동그라미, 물결 밑줄), 화살표 번호표, 2단계 흐름, 다른 시트로 가는 화살표, 보이는 모양 3가지(색연필, 형광 마커, 펜). 처음부터 켜진 대표 기능이에요.
- 빠른 띠, 커서 옆 합계 HUD(고른 칸 옆에 붙이기도), 색깔별 합계 막대, 구성 모듈 진행 막대를 넣었어요.
- 작업 프로필 6종(정산·회계 마감, 데이터 정리, 검수·감사, 수식 따라가기 등)과 모듈 기본 모양 고르기를 넣었어요.
- 모듈을 아이콘으로 줄이는 모양과 일하는 중 숨 쉬는 점을 넣었어요.
- 패널을 작게(한쪽에 5~6개) 하고, 패널마다 투명도 5단계를 넣었어요. 도크 하나(왼쪽)가 기본이에요.
- 편집 모드에서 도크 끌기와 복원 누락을 고쳤어요.

# 사이드바 묶음 탭과 끌어 옮기기, 높이 손잡이 (2026-11-17)

## 사용자 요청 (2026-11-17)
> 기능별로 따로따로 탭이 생기네? 그룹화되어서 오른쪽 탭으로 묶여 있으면 좋을 듯. 사이드 패널 형태가 디폴트면 더 좋을 것 같음.
> 드래그 앤 드롭으로(너무 막 움직일 것 같으면 토글키+드래그) 그룹 탭을 옮겨 다른 그룹에 넣어 한번에 보게, 사용자가 보고 싶은 것만 묶어서.
> 패널 안 모듈의 상하 높이도 조정할 수 있게.

## 정한 것
1. **사이드바가 기본(오른쪽)**. 설정 `sidebar` 기본값 `right`. 예전 설정 파일(`sidebar: off`)은 처음 한 번만 오른쪽으로 옮긴다(`sidebarIntro` 0→1, `HunsuSettings.WithSidebarDefault`, 읽을 때 `SettingsStore.Load`). 그 뒤 사용자가 끄면 꺼진 채 둔다.
2. **활동 막대 = 묶음 탭**. 기본 묶음은 도크와 같은 기능 묶음(order 범위, `LauncherGroups.Ranges`: 상태·점검·이동·수식·그 밖·참고). 탭을 고르면 그 묶음의 모듈이 위에서 아래로 쌓인다. 모듈이 하나뿐인 탭은 그 모듈 아이콘, 여럿이면 묶음 아이콘 + 귀퉁이 숫자. 쌓아 보기(`sidebarTabs=false`)는 모든 묶음을 머리글과 함께 차례로 쌓고, 탭 아이콘을 누르면 그 묶음으로 내려간다. 접힌(작게) 모듈은 「＋ 이름」 한 줄로 남아 누르면 펴진다. 모두 접힌 묶음을 고르면 모두 펴진다.
3. **끌어 옮기기는 Shift+끌기**(코디네이터 제안은 Alt였으나 바꿈): 엑셀은 Alt를 눌렀다 떼면 리본 단축키 글자가 뜨고, 떼어 낸 패널은 이미 "배치 잠금 locked면 Shift+끌기"라 같은 규칙으로 맞췄다. 배치 잠금 `free`이거나 Ctrl+Alt+H로 부른 동안은 그냥 끈다. 4px 넘게 끌어야 시작하고, 놓을 곳이 아니면 아무것도 안 바뀐다.
   - 탭 아이콘 → 다른 탭 아이콘의 위/아래 30%: 순서, 가운데: 합치기. 모듈 위나 묶음 머리글에 놓아도 합치기.
   - 모듈 제목줄 → 탭 아이콘: 그 묶음 맨 아래, 다른 모듈 위/아래 절반: 그 자리, 끄는 동안 막대 끝에 나타나는 ＋ 칸: 새 묶음(「내 묶음 N」, 열쇠 `my-N`).
   - 탭 아이콘 우클릭 「기본 묶음으로 되돌리기」.
4. **높이 손잡이**: 모듈마다 아래에 가로 손잡이(평소 흐린 짧은 선, 올리면 선명). 끌면 그 모듈 본문 높이(40~1200 DIP), 두 번 누르면 자동(내용만큼). 사이드바에서만 쓰이고 도크로 돌아가면 예전 높이 제한(`panelMaxHeight`)을 따른다.

## 고침: 묶음 순서는 그냥 끌기 (2026-11-17, 판 0.0.181)
- 사용자 요청(스크린샷, 활동 막대 아이콘 두 개): "이 위치에서 순서도 바뀌게". 순서 바꾸기는 되돌리기 쉬우므로 묶음 아이콘은 수정키 없이 끌어도 순서가 바뀐다(위/아래 절반, 아이콘 사이 틈과 막대의 빈 아래쪽 = 맨 끝). 6px 넘게 끌어야 시작해 클릭과 섞이지 않는다.
- 합치기(가운데에 놓기, 모듈·머리글 위에 놓기)와 모듈 옮기기는 그대로 Shift(또는 자유·부르기 중). Shift 상태는 끄는 동안 실시간으로 본다.
- 끄는 동안 앱이 사이드바를 다시 그리면 끌기가 끊기던 틈을 막았다(놓은 뒤에 다시 그림).

## 사이드바 접기·펴기 (2026-11-17, 판 0.0.190)
- 사용자 요청: "사이드바 끄기는 빼고 차라리 사이드바 접기 펼치기 넣어줘". 활동 막대 맨 아래 ✕를 »/« 단추로 바꿨다. 접으면 활동 막대(40 DIP)만 남고 앱 바 예약도 그 폭으로 줄어 엑셀이 넓어진다. 설정 `sidebarCollapsed`에 기억. 접힌 채 묶음 아이콘을 누르면 펴고 그 묶음을 보인다. 끄기는 설정 창 [일반]과 훈 원 메뉴에 남는다.

## 저장
- `layout.json`의 `sideTabs`: `[{key, name, icon, members:[id...]}]`. 비어 있으면 기본 묶음. 처음 끌어 놓을 때 지금 탭 전체를 적는다(`SideTabs.Persist`). 꺼진 모듈은 원래 탭 끝에 남겨 다시 켜면 같은 자리로 온다. 목록에 없는 새 모듈은 기본 묶음 탭(없으면 새로 만들어 맨 뒤)에 들어간다.
- 모듈별 `SideHeight`(0 = 자동).

## 코드
- 계산: `Core/Layout/SideTabs.cs`(Build, MoveModule, MoveTab, MergeTab, NewTab, Persist), 시험 `SideTabsTests`.
- 화면: `Overlay/SidebarWindow.Tabs.cs`(탭·구역·손잡이), `Overlay/SidebarWindow.Drag.cs`(끌어 놓기, OLE 없이 마우스 잡기), 앱 연결 `Shell/ShellController.Sidebar.cs`.

## 못 본 것 / 나중
- 실제 화면(클라우드에 윈도우 없음): 초점을 받지 않는 창에서 Shift 감지와 마우스 잡기, 끄는 이름표 위치, 손잡이 잡기 쉬운지.
- 묶음 이름 바꾸기(초점을 받지 않는 창이라 글 입력이 어렵다: 설정 창에서 하는 방식이 후보), 묶음 아이콘 고르기.

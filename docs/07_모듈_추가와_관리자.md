## 2. 열린 결정과 바꾸는 스위치 (사용자가 일어나서 고르면 한 줄)

| 결정 | 지금 구현(보수적) | 바꾸는 곳 |
|---|---|---|
| 새 모듈을 처음부터 켜 둘까 | **꺼 둠**(선택 요약만 켬). 엑셀 부하를 PC에서 확인하기 전이라서 | `settings.json`의 `enabledByDefault`: 모듈 id를 넣거나 `["*"]`로 전부 켜기. 또는 관리자에서 하나씩 켠다 |
| 관리자 창을 처음에 자동으로 열까 | 안 연다 | `managerOnStart: true` |
| 범위를 끌 때 조회 간격 | 150ms | `queryDragGapMs`(엑셀이 아직 버벅이면 300~500) |
| 평소 조회 간격 | 직전 조회 시간 × 2, 상한 300ms | `queryGapFactor`, `queryMaxGapMs` |
| 바쁨 표시(반투명) 기준 | 600ms | `staleAfterMs` |
| 목록 줄 수 | 모듈 선언 `max`(오류 8, 시트 40, 흐름 6) 이하, 전체 상한 50 | 각 `view.json`의 `max`, 설정 `listMaxRows` |
| 시트 이동의 자리 | 왼쪽 도크 | 선언 `place`를 `edge-right`로, 또는 관리자 [오른쪽] |
| 관리자 여는 길 | 알림 영역 아이콘 우클릭 → "모듈 관리…", 오른쪽 알약 우클릭 → "모듈 관리…" | 전용 단축키는 **만들지 않았다**(단축키는 사용자 결정 사항: Ctrl+Alt+H, Ctrl+Alt+Shift+H) |
| 새 모듈 내려받기 | 칼퇴 레일(카탈로그 `modules` 구역)이 맡는다. 관리자는 **받은** 모듈만 다룬다 | 칼퇴 저장소 일. 훈수꾼 안에서 직접 받는 화면은 사용자 확인 후 |

## 3. 모듈을 하나 더 만들려면 (간단한 수정만으로)
1. `modules/hunsu-예제/` 폴더를 `hunsu-selection`에서 복사하고 파일 이름과 `id`를 맞춘다(폴더 = id = `<id>.hunsu.json`).
2. 선언에서 `data[].topic`(다리 조회 이름), `on`(다시 조회할 신호: sel, change, sheet, book, calc), `commands`(누르면 보낼 명령)를 정한다. 다리에 없는 조회가 필요하면 `addins/clockout-hunsu`에 `CoHunsuQ_<이름>.bas`를 더하고 `CoHunsuApi.bas`의 `Select Case`와 `hello` 목록에 한 줄씩 더한다(CP949+CRLF, `tools\vba_to_cp949.ps1`).
3. `view.json`에서 부품을 쌓는다: `stat`, `text`, `badge`, `divider`, `list`, `button`. 값은 `{주제.경로:형식}`, 보이기 조건은 `showWhen`/`hideWhen`.
4. 시험: `Tests/ModuleToolsTests.cs`의 `RepoModules()` 목록에 id를 더하면 선언·명령·경로 일관성이 검사된다.

## 4. 한계와 다음 일
- **핀 창의 단추·목록은 부르기(Ctrl+Alt+H) 중에만 눌린다**(평소 핀 창은 클릭 통과, docs/01 5장). 도크에서는 늘 눌린다.
- `flow.neighbors`는 같은 시트만. 시트를 넘는 순서도(`precedents`/`dependents` 그래프)와 셀 위 표시층(`mark`, 오류 셀 테두리)은 2단계 일.
- 시트 이름 바꿈은 엑셀에 이벤트가 없어 다음 시트 이동 때 갱신된다.
- 새 신호(change, calc)는 편집이 잦은 책에서 PostMessage가 늘어난다. 틀 쪽 간격 조절이 있지만 PC에서 `bridge.stats`와 체감으로 확인해야 한다.
- 모듈 관리자 창은 일반 창이다(투명 유리 효과·움직임은 안 넣음). 디자인 다듬기는 사용자 취향 확인 후.
- `ManagerWindow`가 `FindResource`로 Theme 이름을 부른다. Theme에 `Hunsu.Surface`(관리자 바탕)를 하나 더했다.
- 모듈 `version`은 0.1.000, 다리 의존 `min_version`은 0.0.011이다. 실제 릴리스 판 번호는 사용자가 정한다.

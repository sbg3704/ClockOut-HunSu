# 새 기능 후보 목록

사용자가 "나중에"로 미룬 아이디어를 모아 둔다. 만들기로 하면 항목을 옮겨 자기 문서(docs/NN)를 만들고 여기서는 링크만 남긴다.
각 항목: 날짜, 사용자 요청, 검토한 방식과 제약, 상태.

## 1. 참조 전용 팝업 창 (2026-11-17, 보류)

**사용자 요청**: 수식을 짜다가 다른 시트 칸을 참조할 때 지금은 새 창으로 엑셀 창을 2개 띄워 작업한다. 함수 작업용 "참조 전용 팝업"에 다른 시트를 띄워 두고, 거기서 칸을 클릭하면 수식에 바로 들어가게 하고 싶다. 사용자 판단: 급하지 않음, 후보로만.

**제약**: 수식 편집 중(입력·참조 모드)에는 엑셀이 COM 호출을 거절한다(RPC_E_CALL_REJECTED). 그 동안에는 시트 값을 읽거나 창을 새로 열 수 없다. 전역 단축키(RegisterHotKey)는 편집 중에도 눌린다.

**검토한 방식**
- **A. 엑셀 새 창을 팝업처럼 (추천)**: 같은 통합문서의 `NewWindow`를 작게 띄워 엑셀 옆·위에 놓고, 끄면 닫아 정리한다. 같은 통합문서의 다른 창을 클릭하면 엑셀이 원래 `Sheet!A1`을 넣어 주므로 범위 끌기, F4, 시트 탭 전환이 그대로 된다. 사용자가 지금 하는 두 창 작업을 자동으로 해 주는 셈.
  - 편집 중에는 창을 못 여니, 켜 두면 계속 떠 있는 토글(단축키 + quick 토글)로 만든다. 편집을 시작하기 전에 켜 두는 사용법.
  - 정리할 것: 훈수꾼이 따라갈 엑셀 창으로 이 창을 잡지 않게 hwnd로 구별(`Window.Hwnd`), 끌 때·훈수꾼 종료 때 닫기, 창 2개인 채 저장하면 다음에 열 때 창 2개로 열리는 문제(다리의 저장 전 사건에서 닫을지 검토), 크기·자리 기억, 사이드바 앱 바와 겹침.
- **B. 훈수꾼이 시트를 직접 그리기**: 미리 읽어 둔 시트를 WPF 미리보기로 그리고, 클릭하면 참조 글자를 수식줄에 쳐 넣는다(포커스를 뺏지 않는 창 + 문자 입력). 모양은 예쁘게 만들 수 있지만 편집 중에는 값을 새로 못 읽고, 한글 입력기 상태와 부딪힐 수 있고, 범위 끌기·F4 같은 엑셀 기본 동작을 다시 만들어야 한다.

**다음에 할 때**: A로 시작하는 것을 사용자에게 카드로 확인 → 모듈 `hunsu-refwin`(가칭, 이름은 위트 있게 다시 정함)과 셸 쪽 창 열고 닫기. "조용한 훈수"(docs/09)에 맞게 팝업 외에 다른 표시는 띄우지 않는다.

# 설정 마법사 (2026-11-22)

> 사용자 요청(2026-11-22): "설정마법사 기능도 넣어서 처음에 내가 어떤 작업을 원하는지나 모양 같은거 고를 수 있도록 안내하고 기능도 안내하고 설정도 도와줘서 사용자가 쓰기 편하게". 판 0.0.246(처음 0.0.230으로 만들었다가 같은 날 보류 → 칼퇴 새 레일 PR#81(0.0.236) 위에 다시 맞춤).

## 1. 무엇을
처음 쓰는 사람이 설정 창의 다섯 쪽을 다 뒤지지 않고 1분 안에 내 일에 맞게 맞추도록 6단계 창으로 안내한다. 고르는 대로 바로 반영·저장된다(설정 창과 같은 길: `ApplyProfile`, `ApplySetting`, `ApplyLook`). 철학 "조용한 훈수"(docs/09)에 맞춰 단계 넘김은 짧게 스미는 움직임(`Hunsu.Fast`, 감속, 튕김 없음)만 쓴다.

| 단계 | 고르는 것 | 쓰는 설정 |
|---|---|---|
| 시작 | 무엇을 맞추는지 세 줄 안내 | 없음 |
| 하는 일 | 작업 프로필 6종 + 내 프로필, **여러 개 함께**(2026-11-22 사용자 요청, 판 0.0.287) + "직접 고를게요" + [내 프로필로 저장] | `profile`, 모듈 켜짐·순서(`Core/Layout/Profiles`). 칼퇴에서 끈 모듈(docs/22, ModuleGate)은 불러오지 않으므로 건드리지 않고, 끈 수만 안내 |
| 자리 | 오른쪽 사이드바(기본) · 왼쪽 · 엑셀 안 도크(작은 그림 카드), 도크면 배치 모양 5종 | `sidebar`, `dockShape` |
| 모양 | 패널 룩 4종, 수식 흐름 그림 3종, 아이콘 세트 6종(견본 아이콘), 아이콘 크기. 오른쪽에 수식 흐름 미리보기(가짜 시트에 실제 FlowSketch·PencilPainter로 그림, 고를 때마다 다시 그려짐) | `skin`, `pencilLook`, `iconProfile`, `dockSize` |
| 쓰는 법 | 단축키(Ctrl+Alt+H, Ctrl+Alt+Shift+H), 훈 원 우클릭, 켜고 끄는 도움 3가지 | `cursorHud`, `quickBar`, `pencilDraw` |
| 끝 | 고른 것 요약, [설정 창 열기] [시작하기] | 없음 |

## 2. 언제 뜨나
- 처음 켤 때(보통 시작만, `--settings` 설정만 모드에서는 안 뜸): `settings.json`의 `setupSeen`이 `SetupWizard.Version`(지금 1)보다 작으면 한 번 뜬다. 끝내든 [나중에 할게요]·Esc로 닫든 `setupSeen`을 적어 다음부터 저절로 뜨지 않는다. 이미 쓰던 사람도 이 판을 처음 켤 때 한 번 본다.
- 다시 열기: 설정 창 머리글 [✦ 설정 마법사], 훈 원 우클릭·알림 영역 메뉴 "설정 마법사…", 사이드바 맨 아래 ✦. `OpenManager("wizard")`도 마법사를 연다(칼퇴에서 열 때 쓸 수 있게).
- 마법사 내용을 크게 바꿔 다시 보이고 싶으면 `SetupWizard.Version`을 올린다.

## 2-1. 여러 프로필과 내 프로필 (2026-11-22 사용자 요청, 판 0.0.287)
- 사용자: "하는 일 중복 선택도 가능하게", "프로필도 여러 개 적용", "사용자 임의로 만드는 기능"(나만의 프로필 = 모듈과 모양을 골라 이름 붙여 저장, 사용자 확인).
- `profile` 설정은 쉼표로 이은 id들(`accounting,review`). 고른 순서대로 모듈을 이어 붙여(겹치면 처음 자리 한 번) 100, 110 … 순서로 켜고 나머지는 끈다(`Profiles.PlanMany`). 빈 목록 = 직접 고름(모듈 그대로).
- 내 프로필은 `customProfiles`(id `my-1`…, 이름 24자, 모듈 id 순서, 선택 `look`: skin·sidebar·dockShape·dockSize·iconProfile·pencilLook). 최대 20개, 같은 이름이면 덮어씀. 지금 켜진 모듈을 담고 [모양도 함께]를 켜면 지금 모양도 담는다. 고를 때 모양도 입히고, 모양 있는 내 프로필을 여럿 고르면 마지막에 고른 것.
- 기능 모듈이 쓰는 설정 키가 아니라 틀의 설정이므로 카탈로그 제작 기준 문서는 안 바뀐다.

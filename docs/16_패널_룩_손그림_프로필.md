# 패널 룩(손그림 프로필) (2026-11-17, 판 0.0.107)

사용자 말씀(2026-11-17): 수식 흐름의 색연필·형광펜·펜 손그림 느낌을 패널 전체 룩으로 쓰는 시안을 보고 "모두 다 프로필로 넣어놓고 디폴트는 B". 시안 그림은 `docs/시안/패널룩_*.png`.

## 1. 무엇이 있나
| 이름(`skin`) | 시안 | 모양 | 밝기 |
|---|---|---|---|
| `penmarker` (기본) | B 펜과 형광펜 | 흰 패널, 잉크 펜 테두리, 제목 글씨 밑 노란 형광펜 칠 | 밝음 |
| `pencilnote` | A 색연필 노트 | 종이색 패널, 연필 테두리(덧그림), 제목줄 색연필 빗금, 종이 결 | 밝음 |
| `chalk` | C 먹빛 유리와 분필 | 어두운 반투명, 분필 테두리(덧그림), 제목줄 아래 네온 밑줄 | 어두움 |
| `plain` | (이전 모양) | 손그림 없음, 설정 `theme`(밝게·어둡게·Windows 따라)를 따름 | theme |

설정 창 [일반] 맨 위 "패널 룩", 또는 settings.json `"skin"`. **켤 때 한 번 정한다(바꾸면 껐다 켬)**: 테마와 같은 규칙(창 틀이 StaticResource라서). 설정 파일에 `skin`이 없는 기존 사용자는 처음 켜면 B가 된다.

## 2. 구조 (모듈은 건드리지 않는다)
- 값: `Core/Settings/SkinChoice.cs`(이름·표, 순수). 새 룩은 표에 한 줄 + `Ui/Theme/Skin<이름>.xaml` 한 파일(색·모서리·`Hunsu.Skin.*`).
- 색: 모든 화면이 이미 `Hunsu.Glass/Text/Accent/Tone.*` 이름만 쓰므로, 룩 XAML이 같은 이름을 다시 정하면 패널·도크·빠른 띠·관리자·모듈 내용이 전부 따라간다(모듈 선언 수정 0).
- 밝기: `ThemePicker.Apply(..., skin)`이 룩의 `ForcedTheme`로 정한다(밝은 룩은 `ThemeLight.xaml` 위에 룩 XAML을 얹음).
- 글꼴: 제목 글꼴(`Hunsu.FontTitle`)을 **Nanum Pen Script**(OFL 1.1, 이미 번들·`vendor/SOURCES.md`에 적힘)로 바꾼다. 본문은 원래 글꼴 그대로(작은 패널에서 읽기 쉽게). 제목 글자 크기는 토큰 `Hunsu.FontPanelTitle`(기본 11, 룩 17).
- 손그림: `Core/Marks/SkinSketch.cs`(순수, 시험됨)가 패널 크기·제목 글자 폭·룩 종류·씨앗(제목)으로 획 목록을 만들고, `Ui/Frame/HandFrame.cs`가 룩 색으로 그린다. `PanelFrame`의 카드 안에 얹혀 있고 카드가 비트맵 캐시라 크기가 바뀔 때만 다시 그린다. 같은 입력은 같은 모양(깜빡임 없음). 기존 색연필 수식 흐름의 `HandRng`·`PencilStroke`·`PencilGrain`을 그대로 재사용했다(같은 코드를 두 번 짜지 않음).

## 3. 아직 안 한 것 (다음에 할 일)
- 도크(훈 원 띠)·빠른 띠·접은 아이콘 원의 **손그림 테두리**는 아직 없다(색만 룩을 따름). 시안의 도크 띠·동그라미 테두리는 `HandFrame`을 그 카드에 얹는 것으로 같은 방식으로 더하면 된다.
- 칩·단추(`Parts`)의 손그림 외곽선, 활성 칩의 형광펜/빗금 칠.
- 룩을 껐다 켜지 않고 바로 바꾸기(창 틀의 StaticResource를 DynamicResource로 바꾸는 큰 손질).
- 패널마다 다른 강조색(시안은 오류 빨강·시트 파랑·흐름 초록): 지금은 룩의 강조색 하나.
- 실제 화면에서 확인(클라우드에는 화면이 없음): 제목 글씨 밑 칠 위치, 손글씨 제목 크기, 연필 결의 진하기, C의 분필 선 굵기.

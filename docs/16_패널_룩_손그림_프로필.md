# 패널 룩(손그림 프로필) (2026-11-17, 판 0.0.107 → 0.0.117에서 바로 바꾸기·작은 요소 외곽선 추가)

사용자 말씀(2026-11-17): 수식 흐름의 색연필·형광펜·펜 손그림 느낌을 패널 전체 룩으로 쓰는 시안을 보고 "모두 다 프로필로 넣어놓고 디폴트는 B". 시안 그림은 `docs/시안/패널룩_*.png`.

## 1. 무엇이 있나
| 이름(`skin`) | 시안 | 모양 | 밝기 |
|---|---|---|---|
| `penmarker` (기본) | B 펜과 형광펜 | 흰 패널, 잉크 펜 테두리, 제목 글씨 밑 노란 형광펜 칠 | 밝음 |
| `pencilnote` | A 색연필 노트 | 종이색 패널, 연필 테두리(덧그림), 제목줄 색연필 빗금, 종이 결 | 밝음 |
| `chalk` | C 먹빛 유리와 분필 | 어두운 반투명, 분필 테두리(덧그림), 제목줄 아래 네온 밑줄 | 어두움 |
| `plain` | (이전 모양) | 손그림 없음, 설정 `theme`(밝게·어둡게·Windows 따라)를 따름 | theme |

설정 창 [일반] 맨 위 "패널 룩", 또는 settings.json `"skin"`. **바로 바뀐다**(0.0.117부터, 테마도 같이). 설정 파일에 `skin`이 없는 기존 사용자는 처음 켜면 B가 된다.

## 2. 구조 (모듈은 건드리지 않는다)
- 값: `Core/Settings/SkinChoice.cs`(이름·표, 순수). 새 룩은 표에 한 줄 + `Ui/Theme/Skin<이름>.xaml` 한 파일(색·모서리·`Hunsu.Skin.*`).
- 색: 모든 화면이 이미 `Hunsu.Glass/Text/Accent/Tone.*` 이름만 쓰므로, 룩 XAML이 같은 이름을 다시 정하면 패널·도크·빠른 띠·관리자·모듈 내용이 전부 따라간다(모듈 선언 수정 0).
- 밝기: `ThemePicker.Apply(..., skin)`이 룩의 `ForcedTheme`로 정한다(밝은 룩은 `ThemeLight.xaml` 위에 룩 XAML을 얹음).
- 글꼴: 제목 글꼴(`Hunsu.FontTitle`)을 **Nanum Pen Script**(OFL 1.1, 이미 번들·`vendor/SOURCES.md`에 적힘)로 바꾼다. 본문은 원래 글꼴 그대로(작은 패널에서 읽기 쉽게). 제목 글자 크기는 토큰 `Hunsu.FontPanelTitle`(기본 11, 룩 17).
- 손그림: `Core/Marks/SkinSketch.cs`(순수, 시험됨)가 패널 크기·제목 글자 폭·룩 종류·씨앗(제목)으로 획 목록을 만들고, `Ui/Frame/HandFrame.cs`가 룩 색으로 그린다. `PanelFrame`의 카드 안에 얹혀 있고 카드가 비트맵 캐시라 크기가 바뀔 때만 다시 그린다. 같은 입력은 같은 모양(깜빡임 없음). 기존 색연필 수식 흐름의 `HandRng`·`PencilStroke`·`PencilGrain`을 그대로 재사용했다(같은 코드를 두 번 짜지 않음).

## 3. 바로 바꾸기 (0.0.117)
`ThemePicker.Apply`가 켤 때와 설정 창에서 `skin`·`theme`을 바꿀 때 같은 길이다. Theme.xaml(어둡게) → ThemeLight(밝은 룩) → Skin*.xaml 순서로 새 값을 읽어 앱 자원에 밀어 넣는다. **붓·그림자는 같은 개체의 색만 바꾸므로** 이미 만들어진 창·패널·아이콘·설정 창이 코드에서 붓을 한 번 쥐고 있어도(`FindResource`) 그대로 따라간다(사전을 더하거나 빼지 않는다). 모서리·글꼴·크기는 앱 자원을 덮어쓰고, 그걸 `DynamicResource`/`SetResourceReference`로 읽는 곳(패널 틀의 모서리·제목 글꼴·크기, 훈 원 글자, 빠른 띠 모서리)이 따라간다. 끝나면 `ThemePicker.SkinChanged`가 올라 `HandFrame`이 다시 그리고 `PanelFrame`이 제목 폭을 다시 잰다. 새 UI에서 룩을 따르게 하려면 **붓은 그대로 쥐어도 되고**, 모서리·글꼴·크기만 `SetResourceReference`로 읽으면 된다.

## 4. 작은 요소의 손그림 외곽선 (0.0.117)
`HandFrame`에 `Mode`: `Panel`(패널 틀), `Ring`(둥근 것: 훈 원, 아이콘 동그라미 — 손으로 한 바퀴 두른 고리), `Box`(알약·빠른 띠 카드 — 손으로 그은 네모). 획 계산은 `SkinSketch.Outline`(순수, 시험됨): 펜은 한 줄, 연필·분필은 덧그림 한 줄 더. `LauncherParts`(Hub·Icon·Pill)와 `QuickBar` 카드에 얹었다. 룩이 plain이면 아무것도 안 그린다.

## 5. 아직 안 한 것 (다음에 할 일)
- 이름 알약(`Tag`)·위쪽 이름표(`Label`)·묶음 이름표의 외곽선(작아서 일부러 뺌: 보고 나서 필요하면 같은 한 줄로 더함), 칩·단추(`Parts`)의 손그림 외곽선, 활성 칩의 형광펜/빗금 칠.
- 설정 창 제목(ManagerWindow)의 글꼴은 창을 다시 열어야 룩을 따른다(`SetResourceReference`로 바꾸면 됨).
- 패널마다 다른 강조색(시안은 오류 빨강·시트 파랑·흐름 초록): 지금은 룩의 강조색 하나.
- 실제 화면에서 확인(클라우드에는 화면이 없음): 제목 밑 칠 위치, 손글씨 제목 크기, 연필 결의 진하기, C의 분필 선 굵기, 룩 바꿀 때 열린 창이 모두 따라오는지.

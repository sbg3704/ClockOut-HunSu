# 13. 최소화 공용 라이브러리 (2026-11-16, 판 0.0.072)

## 왜
사용자 말씀(2026-11-16): 범례만 있는 패널이 패널 한 칸을 다 차지한다. 켜진 모듈은 패널 없이도 일할 수 있으니 **작은 아이콘으로 줄이고, 일하는 중이면 숨 쉬듯 깜빡이고, 누르면 다시 열리게** 하자. 그리고 이 기능은 모듈마다 짜지 말고 공용으로 두자. 색연필 수식 흐름의 그림은 건드리지 않는다.

## 모듈이 하는 일 (코드 없음)
manifest에 한 줄: `"form": "mini"`. 처음 켤 때만(저장된 자리 없음) 패널이 줄어든 채 시작한다. 이후는 사용자가 정한 대로.
- 현재 선언한 모듈: `hunsu-marks`, `hunsu-crosshair`(범례만 있는 패널).
- form 종류: `panel`(기본), `hud`(떼어 낸 반투명 창), `mini`(아이콘으로 시작).

## 공용 부품
| 부품 | 위치 | 하는 일 |
|---|---|---|
| `ActivityTracker` | Core/Layout/Minimize.cs | 모듈이 방금(4초 안) 데이터를 받았는지 기억. 순수 계산 |
| `Minimize.IsWorking` | 같은 파일 | 줄어든 모듈이 일하는 중인가 = 줄어듦 AND (셀 위 표시를 그림 OR 방금 데이터 받음) |
| `Minimize.StartsMinimized` | 같은 파일 | form이 mini인가 |
| `ActivityDot` | Ui/Frame/ActivityDot.cs | 숨 쉬는 점(투명도 0.35~1, 900ms). 아이콘 귀퉁이에 올리면 끝 |
| `LauncherModule.Working` / `QuickItem.Working` | Core/Layout, Overlay | 런처 아이콘·빠른 띠 칸에 점을 그리라는 표시(묶음은 안쪽 하나라도 일하면) |
| `ShellController.Minimize.cs` | Shell | 1초 점검, 바뀔 때만 다시 그림. `ApplyMiniForms`가 처음 한 번 줄임 |

## 동작
- 패널 머리 단추 ‘접기’는 이제 ‘작게(아이콘으로)’. 줄어든 모듈은 런처·빠른 띠에 아이콘으로 남는다(기존 접기 구조 그대로).
- 아이콘 귀퉁이 점: 줄어든 모듈이 일하는 중일 때만 깜빡인다. 패널이 열려 있으면 열림 고리만 보인다.
- 아이콘을 누르면 패널이 펼쳐진다(기존).

## 다른 곳에서 쓰려면
순수 판단(`Minimize`, `ActivityTracker`)은 화면에 의존하지 않는다. 그리기는 `ActivityDot.Create(scope, size)`만 호출하면 된다. 새 모듈은 manifest `form`만 고른다.

## 못 본 것
실제 화면(점 위치·깜빡임 속도·줄어든 첫 모양). 시험: 순수 판단 5개(MinimizeTests).

# 14. 옵션 선언표 (quick) — 우클릭 빠른 설정과 [옵션] 쪽 (2026-11-16, 판 0.0.077)

## 왜
사용자 말씀(2026-11-16): 창을 켜지 않고도 모듈 옵션을 빠르게 바꾸고(우클릭 등), 자세한 건 창에서도 바꿀 수 있어야 한다. 옵션 창·메뉴 띄우기는 라이브러리가 하고, 옵션마다 순서·묶음·추가 메뉴(드롭박스)를 계층으로 선언해 기능 만들 때 바로 알아보게, 코딩량을 줄인다.

## 모듈이 하는 일: manifest에 `quick`만 쓴다
```json
"quick": [
  {"kind":"toggle","key":"pencilDraw","label":"그리기 켜기 (Ctrl+Alt+D)","group":"그리기","order":1},
  {"kind":"choice","key":"pencilLook","label":"그림 모양","group":"그리기","order":2,
   "options":[{"value":"pencil","label":"색연필"},{"value":"marker","label":"형광 마커"},{"value":"ink","label":"펜"}]},
  {"kind":"menu","label":"고급","items":[ {…항목…} ]}
]
```
| 칸 | 뜻 |
|---|---|
| kind | `toggle` 켜기·끄기(체크), `choice` 여러 값 중 하나(드롭박스·하위 메뉴), `menu` 하위 메뉴(안에 항목을 또 넣음) |
| key | settings.json의 키(없는 키는 시험이 잡는다). menu는 없음 |
| label | 보이는 이름 |
| group | 같은 이름끼리 모아 구분선과 작은 제목으로 나눔(없으면 제목 없음) |
| order | 작을수록 위(없으면 선언 순서) |
| options | choice의 `{value,label}` 목록(2개 이상). value가 숫자면 숫자로 저장 |

값은 새 설정 키가 필요하면 `HunsuSettings`에 속성을 더하고(범위 검사 포함) 그 키를 쓴다.

## 라이브러리가 해 주는 일
| 부품 | 위치 | 일 |
|---|---|---|
| `QuickSchema.Read/Arrange` | Core/Manifest/QuickSetting.cs | 선언 읽기·검증, 순서와 묶음 배치(순수, 시험됨) |
| `QuickMenu.Fill` | Ui/Frame/QuickMenu.cs | 우클릭 메뉴로 그림: 묶음 제목·구분선·하위 메뉴·체크 표시 |
| `FillQuick` | Shell/ShellController.QuickMenu.cs | 모듈 아이콘·패널·빠른 띠 우클릭이 열릴 때마다 현재 값으로 채움 |
| `OptionsPage` | Shell/OptionsPage.cs | 설정 창 [옵션]: 모든 모듈 선언을 모듈별로 모아 같은 계층으로 그림 |
| `ApplySetting` | Shell/ShellController.Manager.cs | 저장과 바로 반영(그리기 켜고 끄기는 셀 위 그림을 즉시 다시 맞춤) |
메뉴 맨 아래에는 늘 열기·닫기, 핀 창으로 떼기, 반대쪽 도크, **자세히 설정…**(설정 창)이 있다.

## 수식 흐름 그리기 켜고 끄기
- 우클릭 메뉴 [그리기 켜기], 훈 원 우클릭 [수식 흐름 그리기 켜기·끄기], **Ctrl+Alt+D**(전역 단축키, 엑셀이 앞에 있을 때만). 설정 키 `pencilDraw`(기본 켜짐).
- 끄면 그림만 멈추고 모듈은 켜진 채다(줄어든 아이콘의 "일하는 중" 점도 꺼짐). 켜면 값을 새로 받아 바로 그린다.
- 일부러 **엑셀의 Ctrl+클릭**은 쓰지 않았다(다중 선택과 겹치고, 오버레이가 엑셀 입력을 가로채면 안 됨). 마우스로는 아이콘·패널 우클릭을 쓴다. 바꾸고 싶으면 `HotkeyPolicy.DrawKey/DrawMods`.

## 못 본 것
실제 화면(메뉴 모양·하위 메뉴·[옵션] 쪽), Ctrl+Alt+D 등록(다른 프로그램이 쓰면 실패하고 로그에 draw=false). 시험: 선언 읽기·배치·값, 모든 모듈 선언 키가 실제 설정이고 선택지가 그대로 살아남는지(QuickSettingsTests).

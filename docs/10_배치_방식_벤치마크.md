# 10. 배치 방식 벤치마크: 와우 UI 애드온 (2026-11-16)

사용자 요청(2026-11-16): "수정모드, 고정모드, 임시 잠금 해제(Shift 클릭 등)로 모듈에 자율성을 주고, ElvUI·Bartender·Details 같은 UI 애드온의 배치 방식을 벤치마킹". 아래는 내가 아는 내용을 정리한 것이며 최신 판을 직접 열어 확인한 것은 아니다. 사용자 승인 전 확정 아님.

## 1. 애드온들이 공통으로 쓰는 것
| 방식 | 내용 | 훈수꾼에 가져올 것 |
|---|---|---|
| 세 가지 상태 | 잠금(평소), 편집 모드(옮기기), 임시 해제(Shift 누른 채 끌기) | 그대로. 평소 실수로 안 밀리고, 급할 땐 Shift로 바로 옮김 |
| 편집 모드 표시 | 옮길 수 있는 모든 것에 이름표와 윤곽(ElvUI "이동자", 기본 UI 편집 모드) | 편집 모드에서 모든 모듈 창과 도크에 이름 달린 윤곽 |
| 자석과 격자 | 다른 틀 가장자리나 격자에 달라붙음 | 가장자리·다른 모듈 창에 붙기, Alt로 자석 끄기 |
| 미세 이동 | 선택 후 방향키 1칸, Shift+방향키 10칸 | 편집 모드에서 방향키 |
| 앵커 | 틀은 화면 모서리나 다른 틀 기준 오프셋으로 저장(해상도가 바뀌어도 유지) | 엑셀 창 모서리 기준 오프셋으로 저장 |
| 초기화 | 틀 하나, 전체 되돌리기 | 모듈별 "자리 처음으로" 추가(전체는 이미 있음) |
| 프로필 | 이름 붙인 배치 저장·전환(예: 노트북/모니터) | 2단계 후보 |
| 보이기 규칙 | 전투·그룹 등 조건에 따라 숨김, 쉴 때 흐리게(Bartender 페이드) | 엑셀이 비활성일 때 숨김, 쉴 때 흐림(있음) |
| 전체 잠금과 개별 잠금 | 모두 잠금 스위치와 틀별 잠금 | 설정의 전체 잠금(있음 `layoutLock`)과 모듈별 잠금 |

## 2. 훈수꾼 상태 모델 제안
1. **고정(기본)**: 아무것도 안 움직임. 클릭은 엑셀로 통과하거나 모듈 동작만 함.
2. **임시 해제**: Shift를 누른 채 제목줄을 끌면 옮겨짐(떼어 낸 창은 구현됨, 도크는 다음).
3. **편집 모드**(Ctrl+Alt+H): 모든 모듈 윤곽과 이름표, 끌어서 이동, 자석, 방향키, 우클릭 메뉴(자리·잠금·처음으로). 다시 누르면 고정.
4. **모듈별 잠금**: 편집 모드에서 자물쇠로 한 모듈만 고정.

## 3. 자리 선택(사용자 의견 "도크가 좌우에만 있지 않게")
- 도크를 화면 네 변과 모서리에서 자유롭게 놓는다(편집 모드에서 끌어 가까운 변·모서리에 자석).
- 한 변 안에서 위치도 오프셋으로 저장한다.
- 모듈은 도크 안, 떼어 낸 창, 다른 도크로 끌어 옮긴다.

## 4. 구현 순서
1단계(구현됨) 떼어 낸 창 Shift 끌기, `layoutLock`. 2단계 편집 모드 윤곽·이름표·모듈별 잠금. 3단계 도크 자유 배치(네 변, 오프셋). 4단계 자석, 방향키, 프로필.

## 5. 소스로 확인한 내용 (2026-11-16, C:\CO\references의 zip 4종: ElvUI 16.01, Bartender4 4.18.4.1, EllesmereUI 9.8.8, Plater v664)
**라이선스**: ElvUI와 EllesmereUI는 "모든 권리 보유"(사용 권한만 허용), Bartender4는 GPL 계열로 보임(헤더 확인, 전문은 못 봄), Plater는 확인 안 함. 훈수꾼은 허용형만 쓰는 규칙이라 **코드는 복사하지 않고 방식만 참고**한다.

| 애드온 | 확인한 방식 | 훈수꾼에 가져올 것 |
|---|---|---|
| ElvUI `Movers.lua` | 이동자마다 이름표. 끌기 시작하면 격자가 0.75초에 걸쳐 나타남. 끌 때 Sticky(가장자리 자석), 놓으면 화면 모서리 기준 앵커로 다시 저장. 이동자 클릭=미세 이동 창, **마우스 휠=세로 1칸, Shift+휠=가로 1칸**, **Ctrl+우클릭=이 이동자만 처음으로**, **Shift+우클릭=이동자 잠깐 숨김**, 우클릭=그 모듈 설정 열기. 전투 중엔 편집 거부 | 휠·방향키 미세 이동, Ctrl+우클릭 개별 초기화, 우클릭으로 모듈 설정, 자석 on/off, 앵커 기준 저장 |
| Bartender4 `Bar.lua` | 막대마다 `alpha`(투명도), `fadeout`(쉴 때 흐려짐), `fadeoutalpha`(흐릴 때 값), `fadeoutdelay`(마우스 떠나고 흐려지기까지 지연), `visibility` 조건 규칙. **전체 잠금 `Locked`와 막대별 `Lock/Unlock`**: 풀면 보이는 규칙이 꺼져 항상 보이고 윤곽이 생김. 옮기기 시작 때 자석 모드로 재앵커 | **모듈별 투명도, 쉴 때 흐림 값과 지연**(요청하신 "올린 창 투명도"), 잠금 해제 중엔 숨김 규칙 무시 |
| EllesmereUI `UnlockMode*` | 편집 모드(Unlock Mode)로 들어가면 위쪽 배너에 **격자(흐림/밝음/끔 순환), 어둡게 가리기, 자석 on/off, 배너 크기, [나가기] [저장하고 나가기]**. 요소는 한 곳에 등록(`RegisterUnlockElements`: key, 저장/불러오기/지우기/적용 함수 네 개)해서 어느 애드온이든 같은 편집 모드에 참여. 요소끼리 **앵커(어느 변에 붙임)와 너비·높이 맞춤** 링크. 위치는 세션 동안 임시로 두었다가 **저장하고 나가기/버리고 나가기**. 전투 중엔 대기 후 적용. 상태별(전문화) 배치 덮어쓰기 `SpecOverrides` | 편집 모드 위쪽 띠(격자·자석·저장·취소), 모듈이 위치 저장/적용 네 함수를 낸다는 규칙(우리는 선언형이라 프레임이 대신), **저장/취소 세션**, 모듈끼리 변 붙이기와 너비 맞추기, 통합 문서별 배치 덮어쓰기(후보) |
| Plater | 큰 설정 창 하나에 탭, 프로필 가져오기·내보내기(압축 문자열), 모양·조건 스크립트 | 프로필 내보내기·가져오기(문자열 한 줄)는 4단계 후보. 스크립트는 코드 실행 금지 원칙상 제외 |

## 6. 이 비교로 바뀐 제안
1. 편집 모드는 "켜면 즉시 반영"이 아니라 **세션**(저장하고 나가기 / 버리고 나가기)으로 한다. 실수로 끌어도 되돌릴 수 있다.
2. 모듈마다 **투명도**(0.2~1.0), **쉴 때 흐림**(켬/끔, 흐릴 때 값, 지연 초)을 둔다. 창 설정은 레이아웃 저장 파일의 `Opacity` 칸을 쓰고, 흐림 값 둘은 새로 더한다.
3. 마우스 휠로 위치 미세 이동은 엑셀 스크롤과 겹치므로 **편집 모드 안에서만**.
4. 잠금 해제 중에는 모든 모듈이 보인다(숨김·흐림 규칙 무시).

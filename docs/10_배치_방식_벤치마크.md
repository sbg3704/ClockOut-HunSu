# 10. 배치 방식 벤치마크: 와우 UI 애드온 (2026-11-16)

사용자 요청(2026-11-16): "수정모드, 고정모드, 임시 잠금 해제(Shift 클릭 등)로 모듈에 자율성을 주고, ElvUI·Bartender·Details 같은 UI 애드온의 배치 방식을 벤치마킹". 아래는 내가 아는 내용을 정리한 것이며 최신 판을 직접 열어 확인한 것은 아니다. 사용자 승인 전 확정 아님.

## 1. 애드온들이 공통으로 쓰는 것
| 방식 | 내용 | 훈수꾼에 가져올 것 |
|---|---|---|
| 세 가지 상태 | 잠금(평소), 편집 모드(옮기기), 임시 해제(Shift 누른 채 끌기) | 그대로. 평소 실수로 안 밀리고, 급할 땐 Shift로 바로 옮김 |
| 편집 모드 표시 | 옮길 수 있는 모든 것에 이름표와 윤곽(ElvUI "이동자", 기본 UI 편집 모드) | 편집 모드에서 모든 모듈 창과 도크에 이름 달린 윤곽 |
| 자석과 격자 | 다른 틀 가장자리나 격자에 달라붙음 | 가장자리·다른 모듈 창에 붙기, Alt로 자석 끄기 |
| 미세 이동 | 선택 후 방향키 1칸, Shift+방향키 10칸 | 편집 모드에서 방향키 |
| 앵커 | 틀은 화면 모서리나 다른 틀 기준 오프셋으로 저장(해상도가 바뀌어도 유지) | 엑셀 창 모서리 기준 오프셋으로 저장 |
| 초기화 | 틀 하나, 전체 되돌리기 | 모듈별 "자리 처음으로" 추가(전체는 이미 있음) |
| 프로필 | 이름 붙인 배치 저장·전환(예: 노트북/모니터) | 2단계 후보 |
| 보이기 규칙 | 전투·그룹 등 조건에 따라 숨김, 쉴 때 흐리게(Bartender 페이드) | 엑셀이 비활성일 때 숨김, 쉴 때 흐림(있음) |
| 전체 잠금과 개별 잠금 | 모두 잠금 스위치와 틀별 잠금 | 설정의 전체 잠금(있음 `layoutLock`)과 모듈별 잠금 |

## 2. 훈수꾼 상태 모델 제안
1. **고정(기본)**: 아무것도 안 움직임. 클릭은 엑셀로 통과하거나 모듈 동작만 함.
2. **임시 해제**: Shift를 누른 채 제목줄을 끌면 옮겨짐(떼어 낸 창은 구현됨, 도크는 다음).
3. **편집 모드**(Ctrl+Alt+H): 모든 모듈 윤곽과 이름표, 끌어서 이동, 자석, 방향키, 우클릭 메뉴(자리·잠금·처음으로). 다시 누르면 고정.
4. **모듈별 잠금**: 편집 모드에서 자물쇠로 한 모듈만 고정.

## 3. 자리 선택(사용자 의견 "도크가 좌우에만 있지 않게")
- 도크를 화면 네 변과 모서리에서 자유롭게 놓는다(편집 모드에서 끌어 가까운 변·모서리에 자석).
- 한 변 안에서 위치도 오프셋으로 저장한다.
- 모듈은 도크 안, 떼어 낸 창, 다른 도크로 끌어 옮긴다.

## 4. 구현 순서
1단계(구현됨) 떼어 낸 창 Shift 끌기, `layoutLock`. 2단계 편집 모드 윤곽·이름표·모듈별 잠금. 3단계 도크 자유 배치(네 변, 오프셋). 4단계 자석, 방향키, 프로필.

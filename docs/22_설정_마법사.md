# 설정 마법사 (2026-11-22)

> 사용자 요청(2026-11-22): "설정마법사 기능도 넣어서 처음에 내가 어떤 작업을 원하는지나 모양 같은거 고를 수 있도록 안내하고 기능도 안내하고 설정도 도와줘서 사용자가 쓰기 편하게". 판 0.0.230.

## 1. 무엇을
처음 쓰는 사람이 설정 창의 다섯 쪽을 다 뒤지지 않고 1분 안에 내 일에 맞게 맞추도록 6단계 창으로 안내한다. 고르는 대로 바로 반영·저장된다(설정 창과 같은 길: `ApplyProfile`, `ApplySetting`, `ApplyLook`). 철학 "조용한 훈수"(docs/09)에 맞춰 단계 넘김은 짧게 스미는 움직임(`Hunsu.Fast`, 감속, 튕김 없음)만 쓴다.

| 단계 | 고르는 것 | 쓰는 설정 |
|---|---|---|
| 시작 | 무엇을 맞추는지 세 줄 안내 | 없음 |
| 하는 일 | 작업 프로필 6종 + "직접 고를게요" | `profile`, 모듈 켜짐·순서(`Core/Layout/Profiles`) |
| 자리 | 오른쪽 사이드바(기본) · 왼쪽 · 엑셀 안 도크(작은 그림 카드), 도크면 배치 모양 5종 | `sidebar`, `dockShape` |
| 모양 | 패널 룩 4종, 아이콘 세트 6종(견본 아이콘), 아이콘 크기 | `skin`, `iconProfile`, `dockSize` |
| 쓰는 법 | 단축키(Ctrl+Alt+H, Ctrl+Alt+Shift+H), 훈 원 우클릭, 켜고 끄는 도움 3가지 | `cursorHud`, `quickBar`, `pencilDraw` |
| 끝 | 고른 것 요약, [설정 창 열기] [시작하기] | 없음 |

## 2. 언제 뜨나
- 처음 켤 때: `settings.json`의 `setupSeen`이 `SetupWizard.Version`(지금 1)보다 작으면 한 번 뜬다. 끝내든 [나중에 할게요]·Esc로 닫든 `setupSeen`을 적어 다음부터 저절로 뜨지 않는다. 이미 쓰던 사람도 이 판을 처음 켤 때 한 번 본다.
- 다시 열기: 설정 창 머리글 [✦ 설정 마법사], 훈 원 우클릭·알림 영역 메뉴 "설정 마법사…", 사이드바 맨 아래 ✦. `OpenManager("wizard")`도 마법사를 연다(칼퇴에서 열 때 쓸 수 있게).
- 마법사 내용을 크게 바꿔 다시 보이고 싶으면 `SetupWizard.Version`을 올린다.

## 3. 파일
- `src/ClockOut.Hunsu.Core/Setup/SetupWizard.cs`: 단계·안내 글·요약·보일지(순수 계산, `SetupWizardTests`).
- `src/ClockOut.Hunsu/Shell/SetupWizardWindow.cs`: 창 틀(단계 점, 이전·다음, 키 ← → Esc, 다시 짓기).
- `src/ClockOut.Hunsu/Shell/SetupWizardPages.cs`: 쪽마다 고르는 칸.

## 4. 남은 것
- PC에서 실제 화면 확인(룩마다 카드 색, 좁은 창 줄바꿈).
- 칼퇴 레일에서 마법사를 바로 여는 신호(지금 칼퇴 [설정]은 설정 창 [일반]을 연다).

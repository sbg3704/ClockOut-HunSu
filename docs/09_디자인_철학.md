# 디자인 철학과 도크 규칙 (2026-11-16 확정)

> 상태: 1~5장은 사용자가 2026-11-16 선택지에서 골라 **확정**. 6·7장은 확정안에서 나온 세부 규칙(바꿀 때는 사용자에게 다시 묻는다). 값과 부품 규격은 `docs/03_디자인_기준.md`가 기준이고 이 문서는 그 위의 방향이다.
> 시안: `docs/시안/hunsu-dock.html`(브라우저로 열기) (아티팩트 "훈수꾼 도크 시안")
> 함께 볼 것: 테마 고르기(`dark` 기본·`light`·`auto`)와 패널 너비 `panelWidth`는 PR #15의 `docs/08_계정1_틀_기능_2026-11-16.md`. 이 문서와 어긋나지 않는다.. 참고: Overwolf 도크(둥근 아이콘 무리 + 우클릭 메뉴)는 영감으로만 쓰고 모양을 베끼지 않는다.

## 1. 철학 한 문장 [확정 2026-11-16: 조용한 훈수]
**평소엔 거의 보이지 않고, 필요할 때만 정확히 말한다.** (docs/03 1장 "오래 머무는 것은 조용하게, 변하는 순간에만 움직인다"를 다듬은 것)
- 엑셀이 주인공이다. 훈수꾼은 옆자리 사람처럼 말을 걸 때만 몸을 돌린다.
- 화려함은 "변화"에 쓴다: 새 오류, 값 바뀜, 펼침. 가만히 있는 것은 차분하게.
- 반응이 화려함보다 먼저다. 어떤 효과도 입력 반응을 늦추지 않는다.

## 2. 아이콘 배치 [확정 2026-11-16: A 반달 부채]
- 엑셀 창 가장자리(기본 오른쪽, 왼손잡이 단추로 왼쪽)에 지름 56의 "훈" 원을 반쯤 걸쳐 둔다. 지금의 "훈수꾼" 알약 자리를 대신한다.
- 커서가 가장자리 약 200px 안에 오거나 훈 원을 누르면 켜진 모듈 아이콘(지름 40)이 반지름 160 호를 따라 펼쳐진다. 아이콘 사이 중심 간격 56 이상.
- 모듈이 9개를 넘으면 바깥에 두 번째 호를 둔다. 그래도 넘치면 `order`가 큰 것부터 "더 보기"(docs/01 6.4).
- 아이콘을 누르면 그 모듈 패널이 호 안쪽에 열린다(기존 edge-left/right의 panel). 열린 모듈은 `accent` 2px 고리.
- 클릭 통과: 원과 아이콘, 패널 밖은 모두 엑셀로 지나간다.

## 3. 아이콘 모양 [확정 2026-11-16: 단색 선, 그림은 Fluent + 로고만 직접]
- 유리 원(`glass`, `line` 테두리, `shadow1`) 위에 24 격자 선 아이콘 하나, 굵기 1.5~1.6, 크기는 원 지름의 52%.
- 아이콘 색은 `text` 하나. **색은 상태에만** 쓴다: 숫자 배지(`tone.warn`/`tone.bad`), 열린 모듈 고리(`accent`).
- 그림은 Fluent UI System Icons(MIT)에서 고르고 `Theme`에 이름으로 등록한다. 모듈 선언(`*.hunsu.json`)은 `"icon": "warning"`처럼 **이름만** 쓴다. 훈 로고만 직접 그린다. 오픈소스 판·라이선스는 `vendor/SOURCES.md`에 적는다.

### 3.1 아이콘 세트와 프로필 (2026-11-16 사용자 요청)
- 모듈 선언에는 그림 이름이 아니라 **뜻 이름**만 쓴다: `"icon": "sum"`. 뜻 이름 목록은 `Theme`가 가진다(지금 11개: `sum`, `warning`, `sheets`, `flow`, `tag`, `audit`, `book`, `keyboard`, `graph`, `history`, `mark`).
- **아이콘 프로필** = 세트 하나 + 뜻 이름→그 세트의 그림 이름 짝표. 프로필을 바꾸면 모든 모듈 아이콘이 한꺼번에 바뀐다. 설정 `iconProfile`(기본 `fluent`).
- 프로필에 없는 뜻 이름은 기본 프로필(Fluent) 그림으로, 그것도 없으면 모듈 이름 첫 글자로 그린다.
- 선 굵기는 세트와 관계없이 1.5~1.6으로 맞추고 색은 `text` 하나로 칠한다(채움형 세트는 채움색을 `text`로).
- 그림은 SVG 경로를 빌드 때 XAML `Geometry`로 바꿔 넣는다(실행 중 SVG 해석 없음). 판을 고정하고 `vendor/SOURCES.md`에 적는다.
- 미리 짝지은 표와 그림은 시안 `docs/시안/hunsu-dock.html` 아래 "아이콘 프로필".

## 4. 평소 존재감 [확정 2026-11-16: 반투명 잠듦]
- 평소: 훈 원만 보이고 진하기 45%(설정 15~100%). 펼쳐진 아이콘은 숨는다.
- 경고가 있으면 잠든 동안에도 훈 원 옆에 작은 `warn` 점 하나만. 깜빡이지 않는다.
- 다가가면 `fast`(120ms) 안에 100%로. 패널 투명도 단추 규칙(docs/03 8장)과 같다.

## 5. 움직임 [확정 2026-11-16: 매끄러운 감속]
- 펼침·접힘은 `fast` 120ms, 빠르게 시작해 느리게 끝나는 곡선. 움직이는 속성은 투명도·이동·크기뿐.
- 튕김·차례로 펼침은 쓰지 않는다(2026-11-16 선택에서 뺌).
- 접기는 펼침보다 짧게(80~100ms). 효과 `꺼짐`이면 즉시 나타남.

## 6. 우클릭 메뉴
- 모듈 아이콘: 열기(Enter) · 핀 창으로 떼기 · 순서 앞으로 / ─ / 알림 끄기 · 도크에서 빼기 · 모듈 관리…
- 훈 원: 모듈 관리… · 배치 편집(Ctrl+Alt+H) · 반대쪽 가장자리로 / ─ / 전부 숨김(Ctrl+Alt+Shift+H) · 훈수꾼 끄기
- 메뉴 제목줄에 모듈 이름. 키보드로 열기(메뉴 키, Shift+F10), 첫 항목에 초점, Esc로 닫기.

## 7. 구현할 때 지킬 규칙
1. 색·크기·시간 값은 `Theme`에서만. 모듈은 역할 이름(`accent`, `tone.warn`)과 아이콘 이름만 쓴다.
2. 한 화면의 강조색은 `accent` 하나. 모듈별 고유 색은 쓰지 않는다.
3. 반복 깜빡임 금지. 강조는 `pulse` 한 번.
4. 입력 반응은 80ms 안에 시작, 효과가 끝나기를 기다리지 않는다. 펼침 마지막 프레임 P95 100ms 이내(docs/04).
5. 잠든 상태의 화면 차지는 원 하나(약 30×56px)를 넘지 않는다. 엑셀 열 머리글과 스크롤바를 가리지 않는다.
6. 모든 아이콘은 이름표(툴팁)와 UI 자동화 이름을 가진다. 눌림 영역은 지름 28 이상.
7. 새 아이콘·배치 변경 PR에는 두 테마 × 100%/200% × 효과 꺼짐/화려 그림을 붙인다(docs/03 11장).
